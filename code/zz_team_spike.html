Team folder test (1.2.2 step 0)

A developer test page. It only writes into the folder you pick and into its own test entries — your accounts, contacts and leads are not touched.

1. Who is this?

Give each Chrome profile a different name, e.g. "Boaz" and "Test".


  


  

    
2. The team folder

    
Pick the same OneDrive folder in both profiles ("SalesTeam Team Test").

     
    

  


  

    
3. Write and read

    
Writes one change file for this member, then lists and reads every member's files.

     
    

  


  

    
4. Race: both claim the same account at the same moment

    
Click in BOTH profiles within the same minute. Both write their claim at the next full minute; 10 seconds later each shows the winner. Both must show the same winner.

    
    

  


  

    
5. Many files

    
Writes 300 small files, then reads every member's files, and looks for leftover temporary files (".crswap"). Afterwards, check the OneDrive cloud icon for errors.

    
    

  


  

    
6. Background, with no page open

    
"Close page and test" closes this tab; 10 seconds later the background tries to write into the folder. Wait 20 seconds, open this page again and read the result here.
