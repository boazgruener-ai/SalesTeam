Message / Response Language

      
      
      

        This is the DEFAULT language for everything SalesTeam's AI writes - the Sales Mentor's chat replies,
        Customer Voice's replies, drafted LinkedIn messages, and every other AI-generated text in the
        extension. The one exception: when Customer Voice is grounded in one specific real lead (via
        get_lead_details), it replies in THAT lead's own post language instead, whatever it is - a French
        lead gets a French reaction even if this is set to English, since that's what a real reply from them
        would look like. Everywhere else, this setting is what's actually used.

Restore

      

        Bring your data back from a SalesTeam backup file - the backup zip made on the Backup page (or an older
        .json backup). This is what to use after reinstalling SalesTeam or when setting it up on another computer.
      

      

        After you pick the file you choose what to restore: settings, accounts / contacts / initiatives,
        your edits to them, leads and conversations, the activity log, and display preferences. Only the parts you
        tick are replaced; everything else stays as it is. A safety copy of your current data is saved first.
      

      
      
      

      

        Backups are kept in the folder chosen on the Backup page.
        
      

    


    

      
Backup

      

        One backup holds everything - settings, accounts, contacts, leads, chats and the activity log - as a single dated zip.
        The zip also contains your accounts and leads as CSV spreadsheets, ready to open in Excel or upload to another system.

Revenue & Currency

      

        Revenue reaches SalesTeam written every possible way – 102M, CHF 102m,
        102'000, 1.2bn, sometimes just USD with no number at all. It is cleaned up
        into plain digits (102M becomes 102,000,000) and anything not already in the currency
        below is converted into it, so two figures can actually be compared instead of merely looking different.
        The same clean-up rescues employee counts stored as text, like 6,500+, which otherwise give a
        company no size at all when it is scored.
      


      
      

      

        Exchange rates
        

        

          These are approximate starting values, not a live feed – SalesTeam never calls out to a rates service.
          Correct any of them by hand and set the date so you can see at a glance how old they are. Each one is how
          many US dollars one unit of that currency is worth.
        

        
        
        

        
      

      
    


    

      
Web Findings – Automatic Arbitration

      

        When a web research turns up a fact that disagrees with what an account already holds, most of the time it is
        not a mistake: two correct figures counted differently (84,146 employees or 150,000 – direct staff against
        staff-and-contractors), or a field that is never used to score a company at all. Resolve Web Findings
        Automatically… on the Target Accounts Dashboard settles those by the rules below and leaves you only
        the ones that can genuinely change something. It always shows you what it will do before it does it, writes
        every single decision to the Activity Log, and can be undone in one action.
      


      
Rules

      

        Turning a rule off always moves in the safe direction. For the rules that decide something, that case stops
        being decided and comes to you instead. For the rules that always ask, it stops forcing a question and lets the
        remaining rules try – but a value that fails the “looks wrong” checks is never written into an account
        whatever these are set to, so the most a switched-off rule can do is keep what you already have.
      

      


      
Settings the rules use

      
      
      

        Only used when the two counts fall in different size bands. Higher means fewer questions and more decided for you.
      


      
      
      

        Keeping current data is the safer default: it is the curated set and it is consistent across every account.
        Choose web findings instead if the imported data is older or less trustworthy than a fresh search.
      


      
      

        A count fetched from LinkedIn is the size band the company publishes about itself. It is not an exact headcount,
        but it is the most reliable thing available for putting a company in the right band – so when it disagrees with
        the web research about the band, this keeps LinkedIn's rather than asking you.
      


      

        What counts as a value that “looks wrong”
        

          Checked on both sides – the found value and the one already stored. Alongside these numbers, rule 2 also
          catches an employee count that is not a number at all (values like “6,500+” are stored on some accounts and
          can never be used for sizing), a local employee count larger than the worldwide one, any negative value, and
          revenue that looks like it was entered in millions where the other side is in units.
